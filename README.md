# Video_downloader

**Video Downloader Mini** — скачивание видео и звука (MP3) по ссылке на базе
yt-dlp (PySide6 / Qt6, Windows 10/11).

## Запуск

Двойной клик по `video_downloader.pyw` (Python 3.12+). Зависимости для запуска
из исходников: `python -m pip install -U "PySide6>=6.10.1" yt-dlp`.
На Windows программа берёт только свой `yt-dlp.exe` рядом с собой и скачивает
его сама; ffmpeg/ffprobe — тоже рядом (`ffmpeg/`), с согласия.

## Что умеет

- Вставил ссылку (Ctrl+V или «Вставить») — форматы сканируются сами, качество
  выбирается в списке.
- «Скачать видео» — только варианты со звуком (H.264/MP4 со звуком — запасной
  вариант); после скачивания звук проверяется через ffprobe, немой файл
  помечается `.noaudio`.
- «Скачать только звук» — MP3 (не вышло перекодировать — сохраняется
  оригинальная звуковая дорожка).
- «Отмена», «Открыть папку»; папка загрузок по умолчанию — `downloads/` рядом
  с программой.
- Меню ⚙: стиль и тема окна, «Диагностика форматов», «Обновить yt-dlp»,
  «Обновить ffmpeg/ffprobe», «Обновление с GitHub…», текущий лог и папка
  логов, «О программе».

Настройки (стиль окна, токен и автопроверка обновления) хранятся в QSettings.
Логи — `logs/` (последние 20).

## Обновление с GitHub

⚙ → «Обновление с GitHub…». Нужен токен GitHub «только чтение» (Contents:
Read-only) на репозиторий Video_downloader — кнопка «?» покажет по шагам, как
его получить. Программа сама проверяет новую версию (через 30 с после запуска
и дальше по выбору «Каждые»); есть новая — рядом с ⚙ появляется «⬆ X.Y»,
«Что нового» — из журнала в шапке программы. Ставит только по кнопке
«Обновить», затем перезапуск. yt-dlp.exe, ffmpeg, логи, загрузки и настройки
не трогаются. Обновляется только программа на Python; собранный exe сам не
обновляется.

## Файлы

- `video_downloader.pyw` — программа (журнал изменений — в начале файла).
- `gh_update.py`, `gh_update_qt.py`, `gh_update_help.py` — обновление с GitHub
  (общий модуль).
- `test_gh_update.pyw` — тесты модуля обновления (без сети).
- `release/video_downloader_vX.Y.zip` — архив последней версии.
- До 2.2 главный файл назывался `video_downloader_app_v2.1.pyw` — если он
  остался в папке, его можно удалить (и поменять ярлыки).
